# Salesforce Recruitment CRM

Projeto desenvolvido para aprendizagem prática de Salesforce Administration.

## Objetivo

Criar um CRM de recrutamento capaz de gerir:

- Empresas clientes
- Contactos
- Oportunidades
- Candidatos

## Tecnologias

- Salesforce Sales Cloud
- CRM
- Data Modeling
- Reports
- Dashboards

## Objetos Utilizados

### Standard Objects

- Account
- Contact
- Lead
- Opportunity

### Futuros Custom Objects

- Candidate
- Job Position
- Interview
